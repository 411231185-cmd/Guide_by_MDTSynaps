00 · Что такое и зачем

Разберись один раз — потом не путайся
Критерий 🔴 Remotion 🟢 HyperFrames
Где работает На твоём ПК (Node.js) Прямо в Claude.ai (облако)
Что пишем React-компоненты (JSX) HTML + CSS + JS
Claude рендерит сам ❌ Только пишет код ✅ Рендерит в чате
Нужен ffmpeg ⚠️ Да, обязательно ✅ Нет
Скорость ролика ~4–10 мин (рендер + сборка) ~60 сек
Стоимость Бесплатно (≤3 чел.) Кредиты HeyGen
Массовая генерация из CSV ✅ Идеально ⚠️ Дорого в кредитах
Лучше для Batch 100+ роликов по шаблону Быстрые Reels по запросу
💡
Простое правило: хочешь ролик прямо сейчас → HyperFrames. Хочешь генерировать 100 роликов из Excel бесплатно → Remotion. Лучше всего использовать оба.

02 · Remotion — локальная установка

Node.js 24 уже установлен — осталось 4 шага
1
Установи ffmpeg
Обязательная зависимость для рендера MP4
PowerShell (Admin) 
# Проверь есть ли ffmpeg
ffmpeg -version

# Если нет — установи через winget
winget install ffmpeg

# Или через Chocolatey
choco install ffmpeg

# Проверь после установки
ffmpeg -version
⚠️
После установки ffmpeg перезапусти PowerShell — иначе команда не найдётся в PATH.
2
Создай проект Remotion
Уже выполнено — папка remotion-factory создана
PowerShell 
# Перейди в папку
cd C:\GitHub-Repositories\remotion-factory

# Установи зависимости
npm i

# Запусти превью-студию
npm run dev

После запуска откроется браузер на http://localhost:3000 — это Remotion Studio. Здесь видишь превью своих композиций в реальном времени.

Промпты для вирусных Reels
Скопируй и адаптируй под свою тему
Промпт → HyperFrames (через Claude.ai) 
Создай вертикальный Reels 9:16, 15 секунд.

Формат "Hook → Pain → Solution → CTA":
- 0-2с: крючок — большой текст "ТЫ ТЕРЯЕШЬ ДЕНЬГИ НА ПРОСТОЕ"
- 2-6с: боль — счётчик потерь, красные цифры
- 6-12с: решение — логотип компании, зелёный текст "Решаем за 24ч"  
- 12-15с: CTA — "Звони прямо сейчас" + номер телефона

Стиль: тёмный фон, неоновые акценты, агрессивная типографика.
Добавь shake-анимацию на крючке.
Промпт → Remotion (через Claude Code) 
Напиши Remotion-композицию MyReels в src/MyReels.tsx.
Формат: 1080x1920, 30fps, 15 секунд.

Props интерфейс:
- title: string
- subtitle: string  
- accentColor: string
- logoUrl?: string

Сцены:
1. 0-2с: title влетает снизу с spring() анимацией
2. 2-8с: subtitle появляется fade-in, счётчик через interpolate()
3. 8-13с: центральный блок с логотипом, pulse анимация
4. 13-15с: CTA кнопка, градиентный фон

Зарегистрируй в src/index.ts.

04 · Сделай первый ролик прямо сейчас

HyperFrames готов — просто напиши в чат
→
Скопируй промпт ниже и отправь в чат
Claude вызовет HyperFrames и покажет плеер
Готовый промпт — вставь в чат 
Создай смешной вирусный Reels 9:16, 12 секунд.

Тема: "Когда клиент говорит — сделай как у конкурентов"

Сцены:
- 0-2с: текст "Когда клиент говорит..." (большой, по центру)
- 2-5с: "Сделай как у Apple" (с emoji 🍎, анимация влетает)
- 5-8с: "Только дешевле" (красный текст, shake эффект)
- 8-10с: "И побыстрее" (ещё красный, zoom in)
- 10-12с: мем-реакция текстом + наш логотип MDTSynaps

Стиль: dark mode, яркие акценты, мемный шрифт.
Добавь subtitles снизу.
1
Дождись появления виджета-плеера в чате (занимает ~60 секунд)
2
Нажми Play в плеере — посмотри превью
3
Если всё нравится — напиши в чат: render this as mp4
4
Получи ссылку на скачивание MP4 — готово!
5
Итеративно правь: сделай текст крупнее, измени цвет на красный, добавь музыку
